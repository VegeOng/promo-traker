# 抖店 API 权限申请指引
**负责人操作文档 · 妈子素（MamaVege）**
**平台：抖店（抖音小店，中国国内版）**

---

## 你需要准备的东西
- 抖店**主账号**（店铺管理员，能登录 fxg.jinritemai.com）
- 手机（接收验证码）
- 约 30 分钟时间

## 完成后你需要交给上司的信息
1. App Key
2. App Secret
3. 店铺 ID（shop_id）
4. 授权成功截图

---

## 第一步：登录抖店开放平台

1. 打开浏览器，进入：**https://op.jinritemai.com**
2. 点击右上角 **「登录」**，选择 **「抖店账号登录」**
3. 用店铺主账号扫码/验证码登录
4. 确认左上角显示的是**妈子素**的店铺

> ⚠️ 必须用主账号（管理员），子账号可能没有创建应用的权限

---

## 第二步：入驻成为开发者（如果还没有）

1. 登录后如果提示「入驻」，选择 **「商家开发者」**（不是服务商）
2. 填写基本信息：
   - 开发者名称：**妈子素** 或公司注册名
   - 联系邮箱 / 电话：填公司信息
3. 提交后一般**即时或当天**通过

---

## 第三步：创建自用型应用

1. 进入 **「控制台」→「应用管理」→「创建应用」**
2. 应用类型选择：**「自用型应用」**（重要！不是工具型）
3. 填写：
   - 应用名称：**妈子素数据看板**
   - 应用简介：内部销售数据汇总分析
4. 提交创建

> 自用型应用只服务自己店铺，审核快、不需要上架应用市场

---

## 第四步：申请 API 权限

1. 进入刚创建的应用详情页 → **「权限管理」**
2. 申请以下权限包（找不到一模一样的名字就找最接近的）：
   - ✅ **订单权限包**（订单查询 order.searchList / order.detail）
   - ✅ **商品权限包**（商品查询，可选）
3. 用途说明填写：**内部数据看板，用于公司销售数据汇总分析**
4. 提交等待审核（通常 1–3 个工作日）

---

## 第五步：绑定店铺授权

1. 应用详情页 → **「店铺授权」**（或「授权管理」）
2. 把**妈子素抖店**授权给这个应用
3. 授权成功后记录 **店铺 ID（shop_id）**

---

## 第六步：记录凭证

1. 应用详情页 → **「基础信息」**
2. 记录并截图：
   - **App Key**
   - **App Secret**（点「查看」需要验证身份）

> ⚠️ App Secret 非常重要，截图后直接私信给上司，不要发群

---

## 交付清单

- [ ] App Key
- [ ] App Secret
- [ ] 店铺 ID（shop_id）
- [ ] 订单权限审核通过截图

拿到以上信息后交给上司，技术端会完成数据串联（订单自动同步到公司数据库，与微信小店同一套体系）。
