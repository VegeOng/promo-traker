抖店订单导入
从抖店后台导出订单 Excel，拖到下方上传。系统自动识别列、去重入库，与微信数据并排显示。
① 如何从抖店导出订单
1. 登录抖店商家后台 fxg.jinritemai.com → 「订单」→「订单管理」
2. 选好时间范围（建议按周/月）→ 点「导出」
3. 到「导出记录」下载生成的 Excel 文件
4. 把下载的 .xlsx / .csv 文件拖到下面 👇
② 上传文件
📄
点击选择 或 拖拽 Excel/CSV 文件
支持 .xlsx / .xls / .csv
③ 确认列对应（系统已自动识别，如有错请手动改）
④ 数据预览（前 8 行）· 共 0 笔订单
